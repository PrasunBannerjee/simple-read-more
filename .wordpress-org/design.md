# Simple Read More — brand reference

Quick reference for anyone producing more assets later (screenshots, a
social preview image, a README header). The icon, banner, and manual
already apply this system; use it to keep anything new consistent with
them rather than as a brief for redesigning it.

## Palette

| Role | Value | Use |
| --- | --- | --- |
| Ink | `#1C1C1E` | Primary text, rules, dark grounds |
| Flare | `#E23E1E` | The strike only — decorative, never body copy |
| Paper | `#F1EFEC` | Light ground |
| Flare Deep | `#B4331A` | Small red type on a light ground |
| Flare on Ink | `#F2704F` | Small labels on a dark ground |
| Body | `#3A3A3C` | Running copy on paper |

## Type

DM Sans throughout. Headings are 800 weight, uppercase, tight negative
tracking. Subheads are 700, uppercase, slight positive tracking. Body
stays sentence case at 400, 1.6 line height. IBM Plex Mono is reserved
for code, shortcodes, and file names — nowhere else.

## Mark

Five horizontal rules of one thickness, arranged full / short / full /
short / full, struck through between the third and fourth rule by one
full-width Flare rule that crosses nothing else. The two rules below the
strike sit at 45% opacity — content that exists but hasn't been
revealed yet, which is the whole idea of the plugin stated as a shape.
Never reproduced below 32px; never tiled, outlined, or given a
background shape of its own.

## Tone

Plain, quiet, confident. Closer to a well-set page of type than a SaaS
landing page. No mascot, no gradients, no drop shadows doing the work
contrast should do.
