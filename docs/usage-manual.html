A reader lands on your page and sees this sentence, and nothing past it.

Getting there takes three steps

  1. 01

    Install and activate

    Plugins → Add New Plugin → search "Simple Read More" → Install Now → Activate. Ordinary WordPress, nothing special.

  2. 02

    Type the marker

    Anywhere in your content, on its own line, at the point where you want the split:

    [readmore]
  3. 03

    Publish

    Everything before the marker stays visible. Everything after it collapses behind a "Read More" link. View the page — it already works.

That's the manual. Everything from here down is optional reading for the handful of people who want more control or hit an edge case.

Why there's no settings screen

Most plugins in this category ship an options panel: pick your colors, pick your animation, pick your breakpoints. That's not an oversight here — it was left out on purpose.

A settings screen is a promise that something might go wrong without it, and a maintenance surface that has to keep working across every WordPress and PHP version forever. This plugin does one job — split content at a marker, reveal it on click — and does it the same way for everyone. The one thing worth controlling, the wording of the two links, is still changeable; it just lives in a filter instead of a screen, so updating the plugin can never quietly reset it.

Lightweight isn't the marketing description. It's the actual mechanism: no database writes, no admin page to render, no options to migrate between versions. Activate it and it is already doing its job.

Using it somewhere shortcodes don't run

Most widgets and blocks process [readmore] normally. A few raw-HTML contexts don't. In those, paste this instead — it behaves identically:

<span class="srm-marker"></span>

The span is intentionally empty; nothing needs to go inside it.

One marker per block. Two separate Read More sections need two separate text blocks. A second marker inside content that's already collapsed won't split independently.

Two edge cases, handled automatically

  • A marker typed mid-sentence, rather than alone on its own line, still works — the sentence splits at that exact point.
  • A bulleted or numbered list right after the marker still renders correctly; the plugin is careful never to break a list's markup while hiding it.
Accessibility

Both toggles are real links under the hood — that's deliberate, since it's what lets them automatically inherit your theme's existing link color and underline style rather than looking like a foreign UI element dropped into your content.

  • Reachable and operable with a keyboard alone: Tab to focus, Enter or Space to activate.
  • Announced correctly by screen readers as expand/collapse controls, with the current state kept in sync.
  • Collapsed content can't be tabbed into while hidden, so a keyboard user is never dropped silently into something invisible.
  • The reveal is instant rather than animated for any visitor whose system is set to reduce motion.
Customizing the wording, speed, and look

There's no screen for this, so it happens in code — a few lines, added once.

Link wording

In a child theme's functions.php:

add_filter( 'simple_read_more_labels', function ( $labels ) {
	$labels['more'] = 'Show More';
	$labels['less'] = 'Show Less';
	return $labels;
} );

Or, without touching theme files, in wp-config.php:

define( 'SIMPLE_READ_MORE_LABEL_MORE', 'Show More' );
define( 'SIMPLE_READ_MORE_LABEL_LESS', 'Show Less' );

Either survives plugin updates. Editing simple-read-more.php directly also works, but that edit is erased the next time the plugin updates.

Animation speed

In Appearance → Customize → Additional CSS:

.srm-hide-el {
	transition: grid-template-rows 0.6s ease-in-out;
}

Smaller number, faster reveal. ease-in-out tends to read as the smoothest option.

Link color and underline

The toggle links inherit your theme's link styling on purpose, which is why the plugin sets almost nothing of its own. To override that, add a rule rather than edit the plugin's:

.srm-toggle {
	color: #1C1C1E;
	text-decoration: none;
}

A bit more breathing room above the link: margin-top: 1.5em; in that same rule.

Troubleshooting

The link never appears

  • Confirm the plugin shows as active under Plugins.
  • Confirm [readmore] is typed exactly, square brackets included.
  • Confirm there's actually content after the marker — with nothing to reveal, no link is shown, by design.

[readmore] shows up as literal text on the page

That widget isn't processing shortcodes. Use the HTML marker instead — see "Using it somewhere shortcodes don't run" above.

Clicking does nothing

Open the browser console (F12) and look for a red error. This plugin's script has no dependencies and can't conflict with itself, so an error here almost always points to a different plugin or the theme.

The reveal jumps instead of sliding

A caching or minification plugin may be stripping the transition rule, or a theme forces transition: none for its own reduced-motion handling. Temporarily disable CSS minification to confirm.

Updates and conflicts

Nothing here touches WordPress core, the theme, or any third-party API, so most updates are non-events. What's actually worth a glance:

EventRiskWhat to check
WordPress core updateVery lowNothing — only long-stable, non-deprecated functions are used.
Theme switchVery lowNothing — the plugin never touches theme files.
A new plugin, laterMediumA class literally named .srm-toggle, .srm-hide-el, or .srm-marker could collide. Deliberately unlikely, not impossible.
A caching pluginLowExclude assets/css/simple-read-more.css and assets/js/simple-read-more.js from aggressive minification if the animation stops.

If something does break: deactivate the plugin first to confirm it's the cause, then check the console for an error mentioning srm or simpleReadMore.
